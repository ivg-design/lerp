Lesson 1.3: Functions & Closures

Rive Context​

Functions and closures are used inside lifecycle functions. If you need persistent data across frames, store it on self, not in a local variable inside init.

Function Basics​

Defining Functions​

-- Local function (preferred)
local function add(a: number, b: number): number
    return a + b
end

-- Anonymous function
local multiply = function(a: number, b: number): number
    return a * b
end

Multiple Return Values​

local function minMax(a: number, b: number): (number, number)
    if a < b then
        return a, b
    else
        return b, a
    end
end

local min, max = minMax(5, 3)  -- min = 3, max = 5

Closures​

A closure is a function that captures variables from its surrounding scope. These captured variables are called upvalues.

local function makeCounter()
    local count = 0  -- This is captured by the inner function
    return function()
        count += 1
        return count
    end
end

local counter = makeCounter()
print(counter())  -- 1
print(counter())  -- 2
print(counter())  -- 3
Closures in Rive

Closures are especially useful in Rive for:

  • Input listeners (input:addListener(function() ... end))
  • Callbacks
  • Factory functions for parameterized behavior

Exercises​

Exercise 1: Basic Functions ⭐​

--!strict

export type Exercise1 = {}

local function add(a: number, b: number): number
    return a + b
end

function init(self: Exercise1): boolean
    print(add(2, 3))
    print(add(10, -4))
    return true
end

function draw(self: Exercise1, renderer: Renderer)
end

return function(): Node<Exercise1>
    return {
        init = init,
        draw = draw,
    }
end

Exercise 2: Closures Inside init ⭐⭐​

This shows how closures work in Rive scripts when executed inside init.

--!strict

export type ClosureDemo = {}

function init(self: ClosureDemo): boolean
    local function makeCounter()
        local count = 0
        return function()
            count += 1
            return count
        end
    end

    local counter = makeCounter()
    print(counter())  -- 1
    print(counter())  -- 2
    print(counter())  -- 3

    return true
end

function draw(self: ClosureDemo, renderer: Renderer)
end

return function(): Node<ClosureDemo>
    return {
        init = init,
        draw = draw,
    }
end

Exercise 3: Persisting State Across Frames ⭐⭐​

If you need the counter to tick every frame, store the count on self and update in advance.

--!strict

export type FrameCounter = {
    count: number,
}

function init(self: FrameCounter): boolean
    self.count = 0
    return true
end

function advance(self: FrameCounter, seconds: number): boolean
    self.count += 1
    if self.count % 60 == 0 then
        print(`Frames: {self.count}`)
    end
    return true
end

function draw(self: FrameCounter, renderer: Renderer)
end

return function(): Node<FrameCounter>
    return {
        init = init,
        advance = advance,
        draw = draw,
        count = late(),
    }
end
Key Insight

Local variables in init only exist during that function call. To persist data across frames, use self.property.

Exercise 4: Functions That Return Functions ⭐⭐​

Use a factory to create parameterized behavior inside init.

--!strict

export type Exercise4 = {}

local function makeMultiplier(factor: number)
    return function(value: number): number
        return value * factor
    end
end

function init(self: Exercise4): boolean
    local double = makeMultiplier(2)
    local triple = makeMultiplier(3)

    print(double(5)) -- 10
    print(triple(5)) -- 15

    return true
end

function draw(self: Exercise4, renderer: Renderer)
end

return function(): Node<Exercise4>
    return {
        init = init,
        draw = draw,
    }
end
