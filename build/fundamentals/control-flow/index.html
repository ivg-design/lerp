Lesson 1.2: Control Flow & Loops

Rive Context​

Control flow runs inside lifecycle functions. For one-time logic, use init(self). For per-frame logic, use advance(self, seconds) and store state on self.

Conditionals​

If-Then-Else​

if condition then
    -- runs if condition is true
elseif otherCondition then
    -- runs if first was false and this is true
else
    -- runs if all conditions were false
end

If-Then-Else Expressions​

Luau supports inline conditional expressions (no end needed):

local result = if condition then valueA else valueB

-- Can be chained:
local grade = if score >= 90 then "A"
    elseif score >= 80 then "B"
    elseif score >= 70 then "C"
    else "F"

Loops​

Numeric For Loop​

-- Count from 1 to 5
for i = 1, 5 do
    print(i)
end

-- Count down from 5 to 1
for i = 5, 1, -1 do
    print(i)
end

-- Step by 2 (even numbers)
for i = 2, 10, 2 do
    print(i)
end

While Loop​

while condition do
    -- runs while condition is true
end

Repeat Until​

repeat
    -- runs at least once
until condition  -- stops when condition becomes true

Break and Continue​

-- break: exit loop immediately
for i = 1, 100 do
    if i == 10 then break end
    print(i)
end

-- continue: skip to next iteration
for i = 1, 10 do
    if i % 2 == 0 then continue end
    print(i)  -- Only odd numbers
end

Exercises​

Exercise 1: Basic Conditionals ⭐​

--!strict

export type Exercise1 = {}

function init(self: Exercise1): boolean
    local health = 45

    if health <= 20 then
        print("CRITICAL")
    elseif health <= 40 then
        print("Low")
    elseif health <= 70 then
        print("Medium")
    elseif health <= 90 then
        print("High")
    else
        print("Full")
    end

    return true
end

function draw(self: Exercise1, renderer: Renderer)
end

return function(): Node<Exercise1>
    return {
        init = init,
        draw = draw,
    }
end

Exercise 2: If-Then-Else Expressions ⭐​

--!strict

export type Exercise2 = {}

function init(self: Exercise2): boolean
    local score = 75
    local isPremium = true
    local level = 5

    local grade = if score >= 90 then "A" else if score >= 80 then "B" else if score >= 70 then "C" else "F"
    local discount = if isPremium then 20 else 0
    local title = if level >= 10 then "Master" else if level >= 5 then "Expert" else "Novice"

    print(`Grade: {grade}`)
    print(`Discount: {discount}%`)
    print(`Title: {title}`)

    return true
end

function draw(self: Exercise2, renderer: Renderer)
end

return function(): Node<Exercise2>
    return {
        init = init,
        draw = draw,
    }
end

Exercise 3: Numeric For Loops ⭐​

--!strict

export type Exercise3 = {}

function init(self: Exercise3): boolean
    print("Part A: Count up")
    for i = 1, 5 do
        print(i)
    end

    print("Part B: Countdown")
    for i = 5, 1, -1 do
        print(i)
    end

    print("Part C: Even numbers")
    for i = 2, 10, 2 do
        print(i)
    end

    print("Part D: Sum 1-100")
    local sum = 0
    for i = 1, 100 do
        sum += i
    end
    print(`Sum: {sum}`)

    return true
end

function draw(self: Exercise3, renderer: Renderer)
end

return function(): Node<Exercise3>
    return {
        init = init,
        draw = draw,
    }
end

Exercise 4: While Loops ⭐​

--!strict

export type Exercise4 = {}

function init(self: Exercise4): boolean
    local ammo = 5
    while ammo > 0 do
        print(`Firing! Ammo left: {ammo}`)
        ammo -= 1
    end
    print("Out of ammo")

    return true
end

end

return function(): Node<Exercise4>
    return {

end

Exercise 5: Repeat Until ⭐​

--!strict

export type Exercise5 = {}

function init(self: Exercise5): boolean
    local attempts = 0
    local success = false

    repeat
        attempts += 1
        print(`Attempt {attempts}`)
        if attempts >= 3 then
            success = true
        end
    until success

    print("Success!")

    return true
end

function draw(self: Exercise5, renderer: Renderer)
end

return function(): Node<Exercise5>
    return {
        init = init,
        draw = draw,
    }
end

Knowledge Check​

❓What keyword ends an if-then-else block in Luau?
❓What is the syntax for a numeric for loop that counts from 10 down to 1?
❓Which loop always executes at least once?

Common Mistakes​

  1. Forgetting then: if x > 5 then (not just if x > 5)
  2. Missing do in loops: for i = 1, 10 do (not just for i = 1, 10)
  3. Wrong step direction: for i = 10, 1 do won't run - need for i = 10, 1, -1 do
