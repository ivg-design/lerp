Lesson 1.2: Control Flow & Loops

Learning Objectives​

  • Write conditional logic with if/then/elseif/else
  • Use if-then-else expressions (Luau's ternary operator)
  • Implement while, for, and repeat/until loops
  • Use break and continue effectively

Conditionals​

If Statement​

if condition then
    -- code
elseif otherCondition then
    -- code
else
    -- code
end

Example:

local health = 45

if health <= 20 then
    print("CRITICAL")
elseif health <= 40 then
    print("Low")
elseif health <= 70 then
    print("Medium")
elseif health <= 90 then
    print("High")
else
    print("Full")
end

If-Then-Else Expressions​

Luau has a ternary-style expression syntax (no end needed!):

local result = if x > 0 then "positive" else "non-positive"

-- Can be chained:
local grade = if score >= 90 then "A"
    elseif score >= 80 then "B"
    elseif score >= 70 then "C"
    else "F"
Expression vs Statement

Use expressions for simple value assignments. Use statements when you need multiple lines of code in each branch.

Loops​

Numeric For Loop​

-- Count up: 1 to 10
for i = 1, 10 do
    print(i)
end

-- Count down: 10 to 1
for i = 10, 1, -1 do
    print(i)
end

-- Custom step: 2, 4, 6, 8, 10
for i = 2, 10, 2 do
    print(i)
end

While Loop​

Runs while condition is true:

local health = 100
local damagePerHit = 23

while health > 0 do
    health -= damagePerHit
    print(`Health: {health}`)
end

Repeat-Until Loop​

Runs at least once, continues until condition is true:

local level = 1
local exp = 450

repeat
    if exp >= 100 then
        level += 1
        exp -= 100
        print(`Level up! Now level {level}`)
    end
until level >= 5 or exp < 100

Loop Control​

Break​

Exit the loop immediately:

-- Find first number divisible by 7 between 50-100
for i = 50, 100 do
    if i % 7 == 0 then
        print(`Found: {i}`)
        break  -- Stop searching
    end
end

Continue​

Skip to the next iteration:

-- Print numbers 1-10, but skip multiples of 3
for i = 1, 10 do
    if i % 3 == 0 then
        continue  -- Skip this iteration
    end
    print(i)
end
-- Output: 1, 2, 4, 5, 7, 8, 10

Practice Exercises​

Exercise 1: Health Status System​

function init(self): boolean
    local health = 45  -- Try: 15, 35, 55, 85, 100

    -- Write an if/elseif/else chain that prints:
    -- "CRITICAL" if health <= 20
    -- "Low" if health <= 40
    -- "Medium" if health <= 70
    -- "High" if health <= 90
    -- "Full" if health > 90

    return true
end

Exercise 2: If-Then-Else Expressions​

function init(self): boolean
    local score = 75
    local isPremium = true
    local level = 5

    -- Use if-then-else EXPRESSIONS (single line, no 'end'):
    local grade = -- "A" if >= 90, "B" if >= 80, "C" if >= 70, else "F"
    local discount = -- 20 if isPremium, else 0
    local title = -- "Master" if >= 10, "Expert" if >= 5, else "Novice"

    print(`Grade: {grade}`)      -- C
    print(`Discount: {discount}%`) -- 20%
    print(`Title: {title}`)      -- Expert

    return true
end

Exercise 3: Numeric For Loops​

function init(self): boolean
    -- Part A: Print numbers 1 to 5
    print("Part A: Count up")
    for i = 1, 5 do print(i) end

    -- Part B: Print countdown from 5 to 1
    print("Part B: Countdown")
    for i = 5, 1, -1 do print(i) end

    -- Part C: Print even numbers from 2 to 10
    print("Part C: Even numbers")
    for i = 2, 10, 2 do print(i) end

    -- Part D: Calculate sum of 1 to 100
    local sum = 0
    for i = 1, 100 do
        sum += i
    end
    print(`Sum 1-100: {sum}`)  -- 5050

    return true
end

Exercise 4: Break and Continue​

function init(self): boolean
    -- Part A: Find first divisible by 7 between 50-100
    for i = 50, 100 do
        if i % 7 == 0 then
            print(`Found: {i}`)  -- 56
            break
        end
    end

    -- Part B: Print 1-10, skip multiples of 3
    for i = 1, 10 do
        if i % 3 == 0 then continue end
        print(i)  -- 1, 2, 4, 5, 7, 8, 10
    end

    return true
end

Challenge: FizzBuzz​

Print numbers 1 to 30, but:

  • Print "Fizz" for multiples of 3
  • Print "Buzz" for multiples of 5
  • Print "FizzBuzz" for multiples of both
function init(self): boolean
    for i = 1, 30 do
        if i % 15 == 0 then
            print("FizzBuzz")
        elseif i % 3 == 0 then
            print("Fizz")
        elseif i % 5 == 0 then
            print("Buzz")
        else
            print(i)
        end
    end
    return true
end

Knowledge Check​

❓What keyword starts a conditional block in Luau?
❓Which loop is guaranteed to run at least once?
❓What does 'continue' do in a loop?

Common Mistakes​

  1. Forgetting then: if x > 5 then (not just if x > 5)
  2. Missing do in loops: for i = 1, 10 do (not just for i = 1, 10)
  3. Wrong operator precedence: Use parentheses when unsure
  4. Infinite loops: Always ensure loop conditions will eventually be false

Self-Assessment Checklist​

  • I can write multi-branch if/elseif/else statements
  • I can use if-then-else expressions without 'end'
  • I understand numeric for loop syntax: for i = start, stop, step do
  • I know when to use while vs repeat/until
  • I can use break to exit a loop early
  • I can use continue to skip iterations
