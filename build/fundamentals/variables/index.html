Lesson 1.1: Variables, Types & Operators

Learning Objectives​

By the end of this lesson, you will be able to:

  • Declare local variables correctly
  • Understand Luau's basic data types
  • Use arithmetic, comparison, and logical operators
  • Apply string interpolation and compound assignments

Variable Declaration​

In Luau, the concept of scope is critical. Scope determines where a variable is accessible.

-- Global variable (AVOID THIS!)
gravity = 9.8

-- Local variable (PREFERRED)
local speed = 50

-- With type annotation
local health: number = 100

Global vs Local Variables​

TypeDeclarationScopeRecommendation
Globalname = valueEverywhereAvoid
Locallocal name = valueCurrent blockAlways use
Avoid Global Variables

Global variables can lead to naming collisions and make code harder to trace and debug. Always use local unless you have a very specific reason not to.

Luau has these fundamental types:

Operators​

Arithmetic Operators​

-- Basic arithmetic
local sum = 10 + 5      -- 15
local diff = 10 - 5     -- 5
local product = 10 * 5  -- 50
local quotient = 10 / 3 -- 3.333...
local floor = 10 // 3   -- 3 (floor division)
local mod = 10 % 3      -- 1 (remainder)
local power = 2 ^ 3     -- 8

Compound Assignment Operators​

local x = 10
x += 5   -- x = x + 5  (15)
x -= 3   -- x = x - 3  (12)
x *= 2   -- x = x * 2  (24)
x /= 4   -- x = x / 4  (6)
x //= 2  -- x = x // 2 (3)

Comparison Operators​

==   -- equal
~=   -- NOT equal (note: not !=)
<    -- less than
>    -- greater than
<=   -- less than or equal
>=   -- greater than or equal

Logical Operators​

and  -- both must be true
or   -- at least one must be true
not  -- negation

String Operators​

-- Concatenation
local full = "Hello" .. " " .. "World"  -- "Hello World"

-- Length
local len = #"Hello"  -- 5

-- String interpolation (backticks)
local name = "Player"
local msg = `Welcome, {name}!`  -- "Welcome, Player!"

Block Scope​

Variables are scoped to the block where they are defined:

local function calculate()
    local result = 10  -- Only exists inside this function

    if result > 5 then
        local message = "High"  -- Only exists inside this if block
        print(message)
    end

    -- print(message)  -- Error: 'message' is out of scope here
end

Closures and Upvalues​

Functions capture variables from their surrounding scope (upvalues). This enables closures:

local function makeCounter()
    local count = 0
    return function()
        count += 1
        return count
    end
end

local nextCount = makeCounter()
print(nextCount())  -- 1
print(nextCount())  -- 2
print(nextCount())  -- 3
Closures in Rive

Closures are especially useful in Rive for callbacks, stateful helpers, and maintaining state between frames.

Exercise 4: Logical Operators​

Task: Determine game states using logical operators.

function init(self: Exercise4): boolean
    local health = 25
    local hasPotion = true
    local inCombat = false
    local level = 10

    -- 1. Is the player low on health? (health < 30)
    local isLowHealth = health < 30

    -- 2. Can the player heal? (low health AND has potion AND NOT in combat)
    local canHeal = isLowHealth and hasPotion and not inCombat

    -- 3. Is the player a veteran? (level >= 10)
    local isVeteran = level >= 10

    -- 4. Should show health warning? (low health AND (in combat OR NOT has potion))
    local showWarning = isLowHealth and (inCombat or not hasPotion)

    print(`Low health: {isLowHealth}`)   -- true
    print(`Can heal: {canHeal}`)         -- true
    print(`Is veteran: {isVeteran}`)     -- true
    print(`Show warning: {showWarning}`) -- false

    return true
end

Knowledge Check​

❓What keyword should you always use when declaring variables?
❓What operator is used for 'not equal' in Luau?
❓What is the result of: 10 // 3
❓What does a closure capture?

Common Mistakes to Avoid​

  1. Forgetting local: Always declare with local
  2. Using !=: Luau uses ~= for not-equal
  3. String concat in interpolation: Inside {} you don't need ..
  4. Division precision: / gives float, // gives floor integer

Self-Assessment Checklist​

  • I can declare local variables with explicit types
  • I understand the difference between = and ==
  • I can use ~= for "not equal" (not !=)
  • I can use compound assignments like += and *=
  • I can use string interpolation with backticks
  • I understand and, or, not logical operators
