## What is LERP?

**LERP** (Luau Education for Rive Professionals) is a comprehensive, interactive course for mastering Rive scripting with Luau. Whether you're a designer learning to code or a developer new to Rive, this course takes you from fundamentals to advanced techniques.

*Why "LERP"? In animation and graphics programming, `lerp()` (linear interpolation) is a fundamental function for smooth transitions - and that's exactly what this course does: smoothly transition you from beginner to professional.*

| [07 - Projects](modules/07-projects/README.md) | Real-world Applications | Advanced |

## Quick Start

### Interactive Course (Recommended)

Open the course directly in LiaScript:

**[Launch Interactive Course](https://liascript.github.io/course/?https://raw.githubusercontent.com/ivg-design/lerp/main/course.md)**

### Local Development

```bash
# Clone the repo
git clone https://github.com/ivg-design/lerp.git
cd lerp

# Option 1: Use LiaScript DevServer
npm install -g @liascript/devserver
liascript-devserver --open

# Option 2: Use VSCode extension
# Install "LiaScript Preview" extension and open course.md
```
