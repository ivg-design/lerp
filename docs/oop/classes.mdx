# Lesson 3.2: Building Classes

## Learning Objectives
- Create proper class constructors using metatables
- Type your classes correctly with `--!strict`
- Use the double-cast pattern for type safety
- Implement methods with proper `self` handling
- Build reusable simulation and drawing classes

---

## Rive Context

Rive does not have built-in classes, so you build your own with metatables. In real Rive projects, **class-like objects belong in Util scripts** and are **instantiated by Node scripts**.

Use classes when you need:
- Reusable simulation objects (springs, timers, particles)
- Consistent drawing logic across multiple elements
- Clean separation between math/logic and rendering

---

## The Strict Class Pattern (Rive-Friendly)

In Lesson 3.1, we learned how `__index` enables shared behavior. Now we'll formalize this into a reusable class pattern that:

1. Works with `--!strict` type checking
2. Has a clear constructor (`new()`)
3. Defines a proper type for instances
4. Supports methods with the colon syntax

```lua
--!strict

local MyClass = {}
MyClass.__index = MyClass

export type MyClass = {
    value: number,
    step: (MyClass, number) -> (),
}

function MyClass.new(value: number): MyClass
    local self = setmetatable({}, MyClass)
    self.value = value
    return (self :: any) :: MyClass
end

function MyClass:step(dt: number)
    self.value += dt
end

return MyClass
```

**Key detail:** In `--!strict`, the double cast `(self :: any) :: MyClass` is required so Luau accepts the metatable instance.

## Practice Exercises

### Exercise 1: Build a Spring Class in a Util Script

This is a Util Script that can be imported by Node scripts.

**File: `Spring.luau` (Util Script)**

```lua
--!strict

local Spring = {}
Spring.__index = Spring

export type Spring = {
    position: number,
    velocity: number,
    target: number,
    stiffness: number,
    damping: number,
    step: (Spring, number) -> (),
    snap: (Spring, number) -> (),
}

function Spring.new(position: number, stiffness: number, damping: number): Spring
    local self = setmetatable({}, Spring)
    self.position = position
    self.velocity = 0
    self.target = position
    self.stiffness = stiffness
    self.damping = damping
    return (self :: any) :: Spring
end

function Spring:step(dt: number)
    local displacement = self.target - self.position
    self.velocity += displacement * self.stiffness * dt
    self.velocity *= math.max(0, 1 - self.damping * dt)
    self.position += self.velocity * dt
end

function Spring:snap(value: number)
    self.position = value
    self.target = value
    self.velocity = 0
end

return Spring
```

### Exercise 2: Use the Class in a Node Script

**Goal**: Animate a square using the Spring class and a script input.

```lua
--!strict

local SpringLib = require("Spring")

export type SpringDemo = {
    target: Input<number>,
    spring: SpringLib.Spring,
    path: Path,
    paint: Paint,
}

function init(self: SpringDemo): boolean
    self.path = Path.new()
    self.path:moveTo(Vector.xy(-12, -12))
    self.path:lineTo(Vector.xy(12, -12))
    self.path:lineTo(Vector.xy(12, 12))
    self.path:lineTo(Vector.xy(-12, 12))
    self.path:close()

    self.paint = Paint.with({
        style = "fill",
        color = Color.rgb(255, 200, 0),
    })

    return true
end

function update(self: SpringDemo)
    self.spring.target = self.target.value
end

function advance(self: SpringDemo, seconds: number): boolean
    self.spring:step(seconds)
    return true
end

function draw(self: SpringDemo, renderer: Renderer)
    renderer:save()
    renderer:transform(Mat2D.withTranslation(self.spring.position, 0))
    renderer:drawPath(self.path, self.paint)
    renderer:restore()
end

return function(): Node<SpringDemo>
    return {
        init = init,
        update = update,
        advance = advance,
        draw = draw,
        target = 160,
        spring = SpringLib.new(0, 30, 6),
        path = Path.new(),
        paint = Paint.new(),
    }
end
```

**Rive workflow:**
1. Create a Util Script named `Spring` and paste Exercise 1.
2. Create a Node Script for Exercise 2 and attach it to a Node.
3. Adjust the `target` input in the sidebar and observe the spring motion.

**Note:** The `Spring` type is exported by the Util script and can be used directly in this Node script.

### Exercise 3: Complete Drawable Sprite Class

**Goal**: Build a sprite class that handles its own path, paint, and drawing.

```lua
--!strict

local Sprite = {}
Sprite.__index = Sprite

export type SpriteType = {
    x: number,
    y: number,
    width: number,
    height: number,
    color: Color,
    path: Path,
    paint: Paint,
}

function Sprite.new(x: number, y: number, width: number, height: number, color: Color): SpriteType
    local self = setmetatable({}, Sprite)
    self.x = x
    self.y = y
    self.width = width
    self.height = height
    self.color = color
    self.path = Path.new()
    self.paint = Paint.new()
    self.paint.style = "fill"
    self.paint.color = color
    Sprite._rebuildPath(self)
    return (self :: any) :: SpriteType
end

function Sprite:_rebuildPath()
    local hw = self.width / 2
    local hh = self.height / 2
    self.path:reset()
    self.path:moveTo(Vector.xy(-hw, -hh))
    self.path:lineTo(Vector.xy(hw, -hh))
    self.path:lineTo(Vector.xy(hw, hh))
    self.path:lineTo(Vector.xy(-hw, hh))
    self.path:close()
end

function Sprite:setColor(color: Color)
    self.color = color
    self.paint.color = color
end

function Sprite:draw(renderer: Renderer)
    renderer:save()
    renderer:transform(Mat2D.withTranslation(self.x, self.y))
    renderer:drawPath(self.path, self.paint)
    renderer:restore()
end

export type SpriteDemo = {
    sprites: {SpriteType},
    elapsed: number,
}

function init(self: SpriteDemo): boolean
    self.sprites = {
        Sprite.new(-60, 0, 50, 50, Color.rgb(255, 0, 0)),
        Sprite.new(60, 0, 30, 60, Color.rgb(0, 255, 0)),
    }
    self.elapsed = 0
    return true
end

function advance(self: SpriteDemo, seconds: number): boolean
    self.elapsed += seconds
    for i, sprite in self.sprites do
        sprite.x += math.sin(self.elapsed + i) * 50 * seconds
    end
    return true
end

function draw(self: SpriteDemo, renderer: Renderer)
    for _, sprite in self.sprites do
        sprite:draw(renderer)
    end
end

return function(): Node<SpriteDemo>
    return {
        init = init,
        advance = advance,
        draw = draw,
        sprites = {},
        elapsed = 0,
    }
end
```

### Exercise 4: The Double Cast Pattern

**Understanding why `(self :: any) :: MyType` is necessary:**

```lua
--!strict

local BadClass = {}
BadClass.__index = BadClass

type BadType = { name: string }

function BadClass.new(): BadType
    local self = setmetatable({}, BadClass)
    self.name = "test"
    -- return self  -- Error! Type is not compatible
    return (self :: any) :: BadType  -- This works
end

-- Why?
-- 1. setmetatable({}, BadClass) returns a table with metatable
-- 2. Luau sees it as a generic table, not BadType
-- 3. :: any tells Luau "trust me, forget the current type"
-- 4. :: BadType tells Luau "treat this as BadType"
```

**Key Insight**: The double cast doesn't change runtime behavior - it only satisfies the type checker.

### Exercise 5: Factory Functions

**Goal**: Create multiple constructor variants for flexible object creation.

```lua
--!strict

local Rectangle = {}
Rectangle.__index = Rectangle

export type RectangleType = {
    x: number,
    y: number,
    width: number,
    height: number,
}

function Rectangle.new(x: number, y: number, width: number, height: number): RectangleType
    local self = setmetatable({}, Rectangle)
    self.x = x
    self.y = y
    self.width = width
    self.height = height
    return (self :: any) :: RectangleType
end

function Rectangle.fromCorners(x1: number, y1: number, x2: number, y2: number): RectangleType
    return Rectangle.new(math.min(x1, x2), math.min(y1, y2), math.abs(x2 - x1), math.abs(y2 - y1))
end

function Rectangle.centered(centerX: number, centerY: number, width: number, height: number): RectangleType
    return Rectangle.new(centerX - width / 2, centerY - height / 2, width, height)
end

function Rectangle.square(x: number, y: number, size: number): RectangleType
    return Rectangle.new(x, y, size, size)
end

function Rectangle:area(): number
    return self.width * self.height
end

function Rectangle:contains(px: number, py: number): boolean
    return px >= self.x and px <= self.x + self.width
       and py >= self.y and py <= self.y + self.height
end

Rectangle.__tostring = function(r: RectangleType): string
    return `Rect({r.x}, {r.y}, {r.width}x{r.height})`
end

export type FactoryDemo = {}

function init(self: FactoryDemo): boolean
    local r1 = Rectangle.new(0, 0, 100, 50)
    local r2 = Rectangle.fromCorners(-50, -25, 50, 25)
    local r3 = Rectangle.centered(0, 0, 80, 40)
    local r4 = Rectangle.square(-20, -20, 40)

    print(`r1: {r1}  area: {r1:area()}`)
    print(`r2: {r2}  area: {r2:area()}`)
    print(`r3: {r3}  area: {r3:area()}`)
    print(`r4: {r4}  area: {r4:area()}`)

    print(`\nr1 contains (10, 10)? {r1:contains(10, 10)}`)
    print(`r1 contains (200, 200)? {r1:contains(200, 200)}`)

    return true
end

function draw(self: FactoryDemo, renderer: Renderer)
end

return function(): Node<FactoryDemo>
    return {
        init = init,
        draw = draw,
    }
end
```

### Exercise 6: When to Use Classes vs. Plain Tables

**Use classes for:**
- Objects with behavior (`step`, `draw`, `reset`)
- Complex state updates across frames
- Multiple instances that share the same logic

**Use plain tables for:**
- Static configuration (`style`, `palette`, `layout`)
- One-off data passed into a function

In Rive, this keeps your Node scripts lean and your Util scripts reusable.

## Common Mistakes

1. **Forgetting `__index`**: Methods won't be found without it
2. **Methods in the type**: Only data properties go in the type definition
3. **Using dot instead of colon**: `obj.method()` won't pass `self`
4. **Missing double cast**: Strict mode will error on the return statement
