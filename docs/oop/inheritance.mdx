# Lesson 3.3: Inheritance & Patterns

## Learning Objectives
- Implement inheritance between classes
- Use intersection types for typed inheritance
- Override methods while calling parent implementations
- Build a complete class hierarchy for drawable objects

---

## Rive Context

In Rive, inheritance is most useful when multiple drawable objects share common behavior (`draw`, `move`, `update`) but differ in geometry or styling. This helps keep Node scripts clean while still producing complex procedural visuals.

**When to use inheritance in Rive:**
- Multiple drawables share a base `draw` or `update` function
- You want different rendering styles for the same geometry
- You need to override behavior without duplicating setup logic

For anything simpler, prefer composition with plain tables.

---

## Prototype Inheritance (Rive Pattern)

Since Luau uses prototype-based OOP, inheritance means linking one prototype to another. When a method isn't found on the child, it looks in the parent.

```
Child instance -> Child prototype -> Parent prototype
```

If a method isn't found on the child, Luau looks it up on the parent via `__index`.

## Practice Exercises

### Exercise 1: Drawable Base + Two Shapes

**Goal**: Create a base `Shape` class and derive `Rect` and `Triangle` from it.

```lua
--!strict

local Shape = {}
Shape.__index = Shape

export type Shape = {
    position: Vector,
    path: Path,
    paint: Paint,
    draw: (Shape, Renderer) -> (),
}

function Shape:draw(renderer: Renderer)
    renderer:drawPath(self.path, self.paint)
end

local Rect = {}
Rect.__index = Rect
setmetatable(Rect, { __index = Shape })

type Rect = Shape & {
    width: number,
    height: number,
    rebuild: (Rect) -> (),
}

function Rect.new(position: Vector, width: number, height: number, color: Color): Rect
    local self = setmetatable({}, Rect)
    self.position = position
    self.width = width
    self.height = height
    self.path = Path.new()
    self.paint = Paint.with({ style = "fill", color = color })
    Rect.rebuild(self)
    return (self :: any) :: Rect
end

function Rect:rebuild()
    local halfW = self.width / 2
    local halfH = self.height / 2

    self.path:reset()
    self.path:moveTo(Vector.xy(self.position.x - halfW, self.position.y - halfH))
    self.path:lineTo(Vector.xy(self.position.x + halfW, self.position.y - halfH))
    self.path:lineTo(Vector.xy(self.position.x + halfW, self.position.y + halfH))
    self.path:lineTo(Vector.xy(self.position.x - halfW, self.position.y + halfH))
    self.path:close()
end

local Triangle = {}
Triangle.__index = Triangle
setmetatable(Triangle, { __index = Shape })

type Triangle = Shape & {
    size: number,
    rebuild: (Triangle) -> (),
}

function Triangle.new(position: Vector, size: number, color: Color): Triangle
    local self = setmetatable({}, Triangle)
    self.position = position
    self.size = size
    self.path = Path.new()
    self.paint = Paint.with({ style = "fill", color = color })
    Triangle.rebuild(self)
    return (self :: any) :: Triangle
end

function Triangle:rebuild()
    local half = self.size / 2

    self.path:reset()
    self.path:moveTo(Vector.xy(self.position.x, self.position.y - half))
    self.path:lineTo(Vector.xy(self.position.x + half, self.position.y + half))
    self.path:lineTo(Vector.xy(self.position.x - half, self.position.y + half))
    self.path:close()
end

export type ShapeDemo = {
    shapes: {Shape},
}

function init(self: ShapeDemo): boolean
    self.shapes = {
        Rect.new(Vector.xy(-90, 0), 120, 70, Color.rgb(255, 120, 90)),
        Triangle.new(Vector.xy(110, 0), 90, Color.rgb(80, 180, 255)),
    }
    return true
end

function draw(self: ShapeDemo, renderer: Renderer)
    for _, shape in self.shapes do
        shape:draw(renderer)
    end
end

return function(): Node<ShapeDemo>
    return {
        init = init,
        draw = draw,
        shapes = {},
    }
end
```

**Key Pattern**: Both `Rect` and `Triangle` inherit the `draw` method from `Shape`, but each defines its own `rebuild` for geometry.

### Exercise 2: Override a Method

**Goal**: Add a stroke outline by overriding `draw` on a child class.

This example extends Exercise 1 by adding an `OutlineRect` that draws both fill and stroke.

```lua
--!strict

-- Base Shape class (same as Exercise 1)
local Shape = {}
Shape.__index = Shape

export type Shape = {
    position: Vector,
    path: Path,
    paint: Paint,
    draw: (Shape, Renderer) -> (),
}

function Shape:draw(renderer: Renderer)
    renderer:drawPath(self.path, self.paint)
end

-- Rect class (same as Exercise 1)
local Rect = {}
Rect.__index = Rect
setmetatable(Rect, { __index = Shape })

type Rect = Shape & {
    width: number,
    height: number,
    rebuild: (Rect) -> (),
}

function Rect.new(position: Vector, width: number, height: number, color: Color): Rect
    local self = setmetatable({}, Rect)
    self.position = position
    self.width = width
    self.height = height
    self.path = Path.new()
    self.paint = Paint.with({ style = "fill", color = color })
    Rect.rebuild(self)
    return (self :: any) :: Rect
end

function Rect:rebuild()
    local halfW = self.width / 2
    local halfH = self.height / 2

    self.path:reset()
    self.path:moveTo(Vector.xy(self.position.x - halfW, self.position.y - halfH))
    self.path:lineTo(Vector.xy(self.position.x + halfW, self.position.y - halfH))
    self.path:lineTo(Vector.xy(self.position.x + halfW, self.position.y + halfH))
    self.path:lineTo(Vector.xy(self.position.x - halfW, self.position.y + halfH))
    self.path:close()
end

-- OutlineRect extends Rect with an additional stroke
local OutlineRect = {}
OutlineRect.__index = OutlineRect
setmetatable(OutlineRect, { __index = Rect })

type OutlineRect = Rect & {
    stroke: Paint,
    draw: (OutlineRect, Renderer) -> (),
}

function OutlineRect.new(position: Vector, width: number, height: number, fill: Color, stroke: Color): OutlineRect
    local base = Rect.new(position, width, height, fill)
    local self = setmetatable(base, OutlineRect) :: any
    self.stroke = Paint.with({ style = "stroke", thickness = 5, color = stroke })
    return self
end

function OutlineRect:draw(renderer: Renderer)
    renderer:drawPath(self.path, self.paint)
    renderer:drawPath(self.path, self.stroke)
end

export type OutlineDemo = {
    shapes: {Shape},
}

function init(self: OutlineDemo): boolean
    self.shapes = {
        Rect.new(Vector.xy(-100, 0), 80, 60, Color.rgb(255, 120, 90)),
        OutlineRect.new(Vector.xy(100, 0), 80, 60, Color.rgb(80, 180, 255), Color.rgb(40, 80, 120)),
    }
    return true
end

function draw(self: OutlineDemo, renderer: Renderer)
    for _, shape in self.shapes do
        shape:draw(renderer)
    end
end

return function(): Node<OutlineDemo>
    return {
        init = init,
        draw = draw,
        shapes = {},
    }
end
```

**Rive takeaway:** Inheritance is most useful when you need to tweak the drawing behavior while keeping shared geometry logic intact.

### Exercise 3: Calling Parent Methods

**Goal**: Extend parent methods rather than completely replacing them.

```lua
--!strict

local Enemy = {}
Enemy.__index = Enemy

type EnemyBase = {
    name: string,
    health: number,
    damage: number,
}

function Enemy.new(name: string, health: number, damage: number): EnemyBase
    local self = setmetatable({}, Enemy)
    self.name = name
    self.health = health
    self.damage = damage
    return (self :: any) :: EnemyBase
end

function Enemy:attack()
    print(`{self.name} attacks for {self.damage} damage!`)
end

function Enemy:describe()
    print(`{self.name}: {self.health} HP, {self.damage} DMG`)
end

-- Boss extends Enemy
local Boss = {}
Boss.__index = Boss
setmetatable(Boss, { __index = Enemy })

type BossType = EnemyBase & {
    phase: number,
    specialAttackName: string,
}

function Boss.new(name: string, health: number, damage: number, specialAttackName: string): BossType
    local base = Enemy.new(name, health, damage)
    base.phase = 1
    base.specialAttackName = specialAttackName
    return setmetatable(base, Boss) :: any :: BossType
end

-- Override attack but also call parent's attack
function Boss:attack()
    Enemy.attack(self)  -- Call parent method with dot notation!
    if self.phase >= 2 then
        print(`{self.name} also uses {self.specialAttackName}!`)
    end
end

function Boss:describe()
    Enemy.describe(self)  -- Call parent
    print(`  Phase: {self.phase}, Special: {self.specialAttackName}`)
end

function Boss:nextPhase()
    self.phase += 1
    self.damage += 10
    print(`{self.name} enters phase {self.phase}!`)
end

export type BossDemo = {
    boss: BossType,
}

function init(self: BossDemo): boolean
    self.boss = Boss.new("Dragon", 500, 25, "Fire Breath")

    self.boss:describe()

    print("\n--- Phase 1 Attack ---")
    self.boss:attack()

    self.boss:nextPhase()

    print("\n--- Phase 2 Attack ---")
    self.boss:attack()

    return true
end

function draw(self: BossDemo, renderer: Renderer)
end

return function(): Node<BossDemo>
    return {
        init = init,
        draw = draw,
        boss = Boss.new("", 0, 0, ""),
    }
end
```

**Key Pattern**: To call a parent method, use `ParentClass.methodName(self)` with dot notation.

### Exercise 4: Complete Drawable Hierarchy

**Goal**: Build a full game object hierarchy with drawing support.

```lua
--!strict

-- Base GameObject
local GameObject = {}
GameObject.__index = GameObject

type GameObjectBase = {
    id: number,
    x: number,
    y: number,
    active: boolean,
}

local nextId = 1

function GameObject.new(x: number, y: number): GameObjectBase
    local self = setmetatable({}, GameObject)
    self.id = nextId
    nextId += 1
    self.x = x
    self.y = y
    self.active = true
    return (self :: any) :: GameObjectBase
end

function GameObject:update(seconds: number) end
function GameObject:draw(renderer: Renderer) end

function GameObject:destroy()
    self.active = false
end

-- DrawableObject extends GameObject with path and paint
local DrawableObject = {}
DrawableObject.__index = DrawableObject
setmetatable(DrawableObject, { __index = GameObject })

type DrawableType = GameObjectBase & {
    path: Path,
    paint: Paint,
}

function DrawableObject.new(x: number, y: number, color: Color): DrawableType
    local base = GameObject.new(x, y)
    base.path = Path.new()
    base.paint = Paint.with({ style = "fill", color = color })
    return setmetatable(base, DrawableObject) :: any :: DrawableType
end

function DrawableObject:draw(renderer: Renderer)
    renderer:save()
    renderer:transform(Mat2D.withTranslation(self.x, self.y))
    renderer:drawPath(self.path, self.paint)
    renderer:restore()
end

-- Box extends DrawableObject
local Box = {}
Box.__index = Box
setmetatable(Box, { __index = DrawableObject })

type BoxType = DrawableType & {
    width: number,
    height: number,
}

function Box.new(x: number, y: number, width: number, height: number, color: Color): BoxType
    local base = DrawableObject.new(x, y, color)
    base.width = width
    base.height = height

    local hw = width / 2
    local hh = height / 2
    base.path:moveTo(Vector.xy(-hw, -hh))
    base.path:lineTo(Vector.xy(hw, -hh))
    base.path:lineTo(Vector.xy(hw, hh))
    base.path:lineTo(Vector.xy(-hw, hh))
    base.path:close()

    return setmetatable(base, Box) :: any :: BoxType
end

-- Circle extends DrawableObject
local Circle = {}
Circle.__index = Circle
setmetatable(Circle, { __index = DrawableObject })

type CircleType = DrawableType & {
    radius: number,
}

function Circle.new(x: number, y: number, radius: number, color: Color): CircleType
    local base = DrawableObject.new(x, y, color)
    base.radius = radius

    local segments = 32
    for i = 0, segments - 1 do
        local angle = (i / segments) * math.pi * 2
        local px = math.cos(angle) * radius
        local py = math.sin(angle) * radius
        if i == 0 then
            base.path:moveTo(Vector.xy(px, py))
        else
            base.path:lineTo(Vector.xy(px, py))
        end
    end
    base.path:close()

    return setmetatable(base, Circle) :: any :: CircleType
end

export type HierarchyDemo = {
    objects: {DrawableType},
    elapsed: number,
}

function init(self: HierarchyDemo): boolean
    self.objects = {
        Box.new(-80, -30, 60, 40, Color.rgb(255, 100, 100)),
        Box.new(80, 30, 40, 60, Color.rgb(100, 255, 100)),
        Circle.new(0, 0, 35, Color.rgb(100, 100, 255)),
    }
    self.elapsed = 0
    return true
end

function advance(self: HierarchyDemo, seconds: number): boolean
    self.elapsed += seconds
    for i, obj in self.objects do
        obj.y = math.sin(self.elapsed * 2 + i) * 20
    end
    return true
end

function draw(self: HierarchyDemo, renderer: Renderer)
    for _, obj in self.objects do
        if obj.active then
            obj:draw(renderer)
        end
    end
end

return function(): Node<HierarchyDemo>
    return {
        init = init,
        advance = advance,
        draw = draw,
        objects = {},
        elapsed = 0,
    }
end
```

**Inheritance chain:**
```
Circle/Box -> DrawableObject -> GameObject
```

Each level adds functionality:
- `GameObject`: position, active state, destroy
- `DrawableObject`: path, paint, basic draw
- `Circle`/`Box`: specific geometry

## When to Use Inheritance in Rive

**Good use cases:**
- Multiple drawables share a base `draw` or `update` function
- You want different rendering styles for the same geometry
- You need to override behavior without duplicating setup logic

**Prefer composition when:**
- Objects don't share meaningful behavior
- The relationship is "has-a" rather than "is-a"
- You need more flexibility than single inheritance provides

## Common Mistakes

1. **Forgetting to link prototypes**: Both the instance AND class need metatable setup
2. **Wrong syntax for parent calls**: Use `Parent.method(self)` not `Parent:method()`
3. **Not using intersection types**: Use `type Child = Parent & { ... }` for proper typing
4. **Deep hierarchies**: Keep inheritance shallow - Rive scripts work best with 2-3 levels max
