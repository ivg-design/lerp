# Contribution Policy

## Purpose

LERP accepts community contributions that improve technical accuracy, clarity, and learning outcomes.

## Accepted Contributions

- Factual fixes and API corrections
- Broken examples, typos, and link repairs
- Clarity improvements for lessons and exercises
- Additions that align with Rive + Luau course scope

## Review Standards

- Content must be technically correct and reproducible.
- Examples should be typed and compatible with current Luau and Rive docs.
- New sections should follow existing tone and structure.
- Claims should cite primary sources when version-sensitive.

## Licensing of Contributions

By submitting a contribution, you agree your changes are provided under the **MIT License** used by this repository.

## Out of Scope

- Promotional or unrelated content
- Unverified claims without primary references
- Changes that reduce instructional clarity or maintainability

## Security and Sensitive Issues

For security or private concerns, use the contact route in [Contact & Transparency](/contact-transparency) instead of opening a public issue.
