# Lesson 1.1: Variables, Types & Operators

## Rive Context: How Your Code Actually Runs

Rive does not execute standalone Luau files. Scripts must follow a protocol and run inside lifecycle functions.

Rive Node scripts must:
1. Define an exported type for the script instance
2. Implement lifecycle functions (`init`, `draw`, optionally `advance`)
3. Return a factory function that returns `Node<YourType>`
4. Be attached to a Node in your Rive file

**Where code goes:**
- Put one-time setup and prints in `init(self)`.
- Use `self` for data that must persist across frames.
- `draw(self, renderer)` is required for the script to appear in the add-to-scene list, even if empty.

**Where output appears:** `print()` goes to Rive's Console panel, not your browser console.

---

## Standard Node Script Template

Use this structure for every exercise in this course:

```lua
--!strict

export type MyScript = {
    -- Persistent fields go here
}

function init(self: MyScript): boolean
    -- Put one-time code here
    return true
end

function draw(self: MyScript, renderer: Renderer)
end

return function(): Node<MyScript>
    return {
        init = init,
        draw = draw,
    }
end
```

:::tip How to Run Any Exercise
1. Create a **Node Script** in Rive (Assets panel → + → Script → Node)
2. Paste the exercise script (full Node script, not just the snippet)
3. Attach the script to a Node (drag onto a shape/group)
4. Open the Console panel
5. Press Play in the State Machine
:::

## Variables in Rive Scripts

- **Local variables** inside `init` exist only while `init` runs.
- **Persistent state** must be stored on `self` if you need it later (e.g., `self.score = 0`).
- **Strict typing** applies to `self` fields; define them in the exported type.

### Basic Types

| Type | Example | Description |
|------|---------|-------------|
| `nil` | `nil` | Absence of value |
| `boolean` | `true`, `false` | Logical values |
| `number` | `42`, `3.14`, `0xFF` | All numbers (integers and floats) |
| `string` | `"hello"`, `'world'` | Text |
| `table` | `{}`, `{1,2,3}` | Arrays and dictionaries |
| `function` | `function() end` | Callable code |

## Operators

### Arithmetic Operators

```lua
local sum = 10 + 5      -- 15
local diff = 10 - 5     -- 5
local product = 10 * 5  -- 50
local quotient = 10 / 3 -- 3.333...
local floor = 10 // 3   -- 3 (floor division)
local mod = 10 % 3      -- 1 (remainder)
local power = 2 ^ 3     -- 8
```

### Compound Assignment Operators

```lua
local x = 10
x += 5   -- x = x + 5  (15)
x -= 3   -- x = x - 3  (12)
x *= 2   -- x = x * 2  (24)
x /= 4   -- x = x / 4  (6)
x //= 2  -- x = x // 2 (3)
```

### Comparison Operators

```lua
==   -- equal
~=   -- NOT equal (note: not !=)
<    -- less than
>    -- greater than
<=   -- less than or equal
>=   -- greater than or equal
```

### Logical Operators

```lua
and  -- both must be true
or   -- at least one must be true
not  -- negation
```

### String Operators

```lua
-- Concatenation
local full = "Hello" .. " " .. "World"  -- "Hello World"

-- Length
local len = #"Hello"  -- 5

-- String interpolation (backticks)
local name = "Player"
local msg = `Welcome, {name}!`  -- "Welcome, Player!"
```

## Exercises

### Exercise 1: Variable Declaration ⭐

**Goal**: Declare local variables and print them from `init`.

```lua
--!strict

export type Exercise1 = {}

function init(self: Exercise1): boolean
    local characterName = "Warrior"
    local level = 5
    local experience = 1250.5
    local hasShield = true

    print(characterName)
    print(level)
    print(experience)
    print(hasShield)

    return true
end

function draw(self: Exercise1, renderer: Renderer)
end

return function(): Node<Exercise1>
    return {
        init = init,
        draw = draw,
    }
end
```

**Expected Console Output:**
```
Warrior
5
1250.5
true
```

## Common Mistakes to Avoid

:::danger Avoid Global Variables
Global variables (declared without `local`) can lead to naming collisions and make code harder to trace and debug. Always use `local` unless you have a very specific reason not to.
:::

1. **Forgetting `local`**: Always declare with `local`
2. **Using `!=`**: Luau uses `~=` for not-equal
3. **String concat in interpolation**: Inside `{}` you don't need `..`
4. **Division precision**: `/` gives float, `//` gives floor integer
