# Corrections Policy

## Commitment

If a lesson, example, or exercise is incorrect or ambiguous, it will be corrected with clear intent and minimal delay.

## Correction Types

- **Technical fix:** incorrect API usage, type mismatch, broken snippet.
- **Clarity fix:** wording that can cause misinterpretation.
- **Reference fix:** stale or incorrect external link.

## How Corrections Are Applied

- Update the affected lesson/exercise.
- Preserve stable paths whenever possible.
- Reflect updates in page metadata and repository history.

## Reporting a Correction

Use the contact channels listed in [Contact & Transparency](/contact-transparency) and include:

- Page URL
- Problem description
- Suggested correction (optional)
